## 4. 真实阻断（未解决，不可宣布完成）

1. **assembler 仍有 4 类外部引用原样进 iframe**（18 项门禁中的 4 FAIL，已在 staging 产物上验证）：内联 `style` 属性里的 `url(https://…)`、`<svg><image href>`、`<meta http-equiv=refresh>`、`<button formaction>`。bundle 里搜 `formaction`/`refresh`/`<image` 拦截字符串均为 0 命中。**这是安全缺陷，不是覆盖不足。** owner：Client。改法建议：属性值全量扫描（任何属性值含 `https?:`/`//`/非 data 的 `url(` 一律拒绝）。
2. **`saveId = input.runtimeInstanceId`**（`game-center-service.ts:251` 仍在）：存档 key 实测为 `saves/<player>/<gameId>/rt-<nonce>.json`，每次运行都变 → Client 的"继续游戏"按固定 saveId 查**永远 absent**，"关闭保存→重开恢复"结构上不成立。我的探针 N0d 不覆盖跨实例恢复，所以 14/14 全过**不代表这一条通过**。owner：Host。
3. **`sqlite-save-backend.ts:207` 仍 `?? defaultPlayerId ?? 'default-player'`**：经 SaveStore 时被上层挡住（实测不可触发），属潜在身份回落。owner：Host。
4. **真实 DSH 内实机链路（DSH-REAL）完全未验**：浏览器执行组装后 iframe 脚本、CSP 继承（`srcdoc` vs `blob:` 二者都未实测）、真实 Gateway 网络传输、关闭保存与重开恢复。阶段0 遗留 5 项（真实模型调用 AUTH-PENDING、流式取消、租约过期、关闭停收探针、多弹层焦点）继续挂账。
