## 4. 确定性无猜求解器规范与规则范围
求解器全程仅依据已公开线索进行逻辑演绎，绝不偷看未翻开底牌。支持的三类规则范围如下：
1. **经典单格饱和直推 (Single-Cell Deduction)**：
   - 剩余所需雷数 == 未翻开邻居数 -> 全部未翻开邻居必为雷；
   - 剩余所需雷数 == 0 -> 全部未翻开邻居必为安全格。
2. **双格集合包含与差集推导 (Pairwise Subset & Difference Deduction)**：
   - 若格子 A 的未知邻居集 $U(A)$ 是格子 B 的未知邻居集 $U(B)$ 的子集 ($U(A) \subseteq U(B)$)：
     - 差集 $U(B) \setminus U(A)$ 中的雷数严格等于 $rem(B) - rem(A)$；
     - 若 $rem(B) - rem(A) == 0$ -> 差集全部格子必为安全格；
     - 若 $rem(B) - rem(A) == |U(B) \setminus U(A)|$ -> 差集全部格子必为雷；
   - 覆盖 1-1, 1-2, 1-2-1, 2-1 等边缘线索拓扑。
3. **全局剩余雷数守恒约束 (Global Mine Count Conservation)**：
   - 全局未标记格子数 == 全局剩余雷数 -> 全部未翻开格子必为雷；
   - 全局剩余雷数 == 0 -> 全部未翻开格子必为安全格。
4. **无猜断言口径与门禁闭环**：
   - 若推理停滞且未达成胜利条件，判定为当前规则下演绎死锁（`DEDUCTION_DEADLOCK`），即“当前求解器基于已知线索无法证明对局全盘无猜”，不轻率断言为数学上必需猜。
   - **彻底杜绝未验证猜雷局**：若 AI 未通过校验且本地搜索超出预算，直接返回 `NO_GUESS_GENERATION_FAILED` 并阻断开局，UI 明确提示重试，默认决不开启未经验证的对局。
