## 4. 真实阻断与未验项（严谨挂账）

1. **真实 GitHub Issues 远端网络拉取未验（MOCK，非 DSH-REAL）**：当前目录拉取全部通过可注入的 mock fetcher 验证，未连真实 GitHub API，避免无授权外联与 token 消耗；真实条件请求（ETag/Last-Modified）未在公网验证。
2. **真实 Git 提交归档/产物下载网络传输未验**：当前测试通过 `bundledSource` 与本地 fixture 文件模拟，真实的 GitHub tarball/zip 流式下载与解压落盘尚未接入。
3. **真实 DSH Profile 目录落盘未验**：安装测试均在 OS 临时目录执行，真实桌面环境下 `<profileDir>/data/gamecenter/games/` 的权限与长路径未实机跑过。
4. **受保护分支审批源同步未验**：目前审批记录由内存与 fixture 直接注入，尚未实现从 `approvals/` 目录拉取与校验 commit 历史的真实逻辑。

## 5. 授权边界（新会话必须遵守）

- **在线环境只读**：不修改在线 `lib/`、`dist/`、profile 数据或 DSH 安装文件；不执行部署、刷新、重启；
