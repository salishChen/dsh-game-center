# 交接：玩家代表

时间：2026-10-20。状态：**阶段1 体验与验收总结，未执行真实实机游玩与付费服务**。本文为事实快照与体验交接，不启动新增研发。

## 1. 职责与所有权边界
- **职责范围**：向项目经理汇报，作为体验研究与验收代理，负责从目录绑定、发现/详情、下载安装、模型选择与缺失能力解释、开始/暂停/继续、额度/费用提示、离线/崩溃恢复与版本迁移视角提出可执行体验反馈；覆盖易用性、中文文案、可访问性及误操作保护。
- **所有权文件**：体验验收脚本与旅程反馈设计，与测试与发布负责人、界面与运行时工程师协作。
- **边界约束**：非真实玩家身份或付费授权人；不获取或透露用户密钥，不替用户同意权限、购买/付费、删除存档、上传数据或发布游戏；遵守“只有项目经理可用 gpt-6.1-sol，本角色及子代理仅使用非 GPT 模型”。

## 2. 成果与证据分栏
- **STATIC（基于设计文档与规范评审）**：
  - 评审 `docs/gamecenter-design.zh-CN.md`，确立核心玩家体验硬要求：
    1. **存档关闭必须保存**：主动关闭或暂停必须触发确定性保存并反馈进度；
    2. **真实失败明确告知**：保存失败必须红字明确警告并提示重试或导出，严禁静默失败或误报“已保存”；
    3. **崩溃恢复诚实反馈**：强退/崩溃恢复必须展示实际检查点时间戳与受损范围，严禁虚假承诺“零丢失”；
    4. **模型能力诚实标明**：明确区分图片理解与生图模型，禁止能力误导；未配置模型时应给出明确引导而非直接报错崩溃；
    5. **误操作与付费保护**：覆盖覆盖存档、清空历史、鲸鲸币扣减的前置确认，取消操作明确免计费规则边界。
- **MOCK / UNIT（用例与脚本规范）**：
  - 输出玩家旅程验收场景清单（安装体验、初次启动、游玩存档、异常关闭恢复）；当前用例全部基于协议规范与本地测试夹具。
- **DSH-REAL（真实实机游玩状态）**：
  - **阶段1 至今没有任何一次真实实机游玩**：运行中的 DSH 桌面环境仍为阶段0探针弹层；扫雷游戏从未在 DSH 游戏中心真实启动过；任何关于“游戏可玩、体验流畅”的描述均属未经实测，不可作为验收依据。

## 3. 真实阻断
1. **实机端到端运行未打通（DSH-REAL 未验）**：DSH 客户端未部署阶段1 候选 bundle，扫雷沙箱加载与 SDK 握手尚未实机验证，无法开展真实玩家操作验收。
2. **存档身份与跨局读回未验证**：宿主当前实现将 `saveId` 绑定到 `runtimeInstanceId`，跨会话读回历史存档的真实体验链路受阻。
3. **真实模型调用未授权（AUTH-PENDING）**：AI 关卡生成全部使用 Mock/Fixture，真实模型生成延迟、配额用尽与错误提示文案未经真实链路检验。
