### 残差 `0xA1317E` 的实测（不是猜）

- 指向它的 4 字节对齐指针字：**1 个**，位置 `0x7B1C8`；
- 该指针**不在**任何已解流的压缩区间内（不是被"跳过整条流"吃掉的那种）；
- 未对齐扫描同样只命中这一个位置（说明它不是"只靠未对齐字才可达"的块）。

结论：**它是被指针引用的块**，不是"扫描可得但未被引用"。所以 38 块的闭合是 `12 (dlen<32) + 25 (dlen>8*clen) + 1 (对方枚举漏收)`，而不是 `... + 1 (未被引用)`。剩下这 1 块必须由对方的枚举实现解释（例如：`0x7B1C8` 是否在他们的指针扫描窗口内、是否被前一条指针的"跳过整条流"逻辑吞掉）。

另记：`ratio_semantics = dlen_over_clen`（排除条件 `dlen > 8*clen`）；`clen_over_dlen` 恒为 0，已弃用，仅作墓碑保留。

## 六、最终收口（2026-10-30 11:2x）

- 对方删掉了一条自造闸门「目标偏移必须 4 字节对齐」（`0xA1317E % 4 == 2`，GBA BIOS 对目标偏移无对齐要求），随后其清单变为 4,451。
- 四桶（A=4,451 对方 / B=4,463 我方）：`shared 4,451 / onlyA 0 / onlyB 12 / fieldMismatch 0`。
- 12 块全部 `dlen < 32`（1/9/10/17/19 字节），是对方 `dlen>=32` 闸门挡掉的；这类长度不可能是图块或字库素材。
- `0xA1317E`（256 字节 = 8 个 32B 图块）在帧 900 的 VRAM 里**命中 0/8**，内容以 `03 00 00 00…` 开头，是数据片段不是图形 ⇒ 不影响资产表，按"已知差异"留档。
- 对方把压缩比上限从 8 放宽到 16：本清单里 `dlen/clen = 8.05~8.40` 的 25 块正是被 8 误杀的（解压长度与头部声明一致、可精确解出、有指针引用）。我方基线本就不加闸门，故不受影响；文档第二节的 25/12 只是"若套用旧闸门会掉多少"，不是产出条件。
- **本 tsv 明确标注 `gates_applied=none`**：它是原始基线，不是"已按闸门筛过"的产物——此前头注没写这一行，容易被读成"文档说加了闸门、数据却违反"，特此更正。

至此 LZ77 口径双方互证：重叠部分 `dlen`/`clen` 逐字相同，剩余 12 块差异是明确的闸门边界（且无资产价值）。

## 七、闸门分类与压缩比阈值的依据（2026-10-30 补）

| 闸门 | category | 依据 | 取值理由 |
|---|---|---|---|
| 指针字 4 字节对齐 | **format** | ARM 取字 / 规范 | 编码约束，删了会把数据片段当指针 |
| 头字节高 4 位 = 1 | **format** | GBATEK BIOS 压缩格式 | 低 4 位为保留位，不参与判定 |
| `dlen` 精确达到 | **format** | 解码算法语义 | 不精确即失败，不做"近似" |
| 回引 `pos >= 0`、自重复允许 | **format** | 解码算法语义 | 逐字节复制，允许 `disp < length` |
| `dlen >= 32` | **scope** | 我们要的是图块/字库 | 8×8 4bpp 图块正好 32 B；1–19 B 的合法流没有资产用途 |
| 压缩比上限 | **scope** | 挡"随机字节冒充块头" | 阈值必须由假阳性分布定，不由想收哪些块定 |

**压缩比阈值的实测依据（洗牌基线，种子 20261030，全字节偏移扫描）**：

```
false_positives = 553
ratio(dlen/clen)  max = 1.778   p99 = 0.750   median = 0.286
```

读法：`ratio` 上限是"假阳性能到多高"的上界，不是"真块能到多低"的下界。若假阳性 max 明显低于 8，则 8 有余量；若接近或超过 8，说明该维度不足以区分真假，应改用"`dlen` 精确 + 被指针引用"作为必要条件。

## 八、资产表口径（定稿）与附录

| 维度 | 取值 | category |
|---|---|---|
| 枚举 | 指针驱动（32 位字，`0x08xxxxxx`） | format |
| 指针字对齐 | 4 字节 | format |
| 头字节 | **精确 `0x10`**（低 4 位必须为 0；`0x1X` 变体只作对照，不进资产表） | format |
| `dlen` | 精确达到（解压后长度） | format |
| `dlen >= 32` | 生效（≥1 个 8×8 4bpp 图块） | scope |
| 压缩比 | 不作为筛选（实测假阳性 max=1.778、p99=0.75、median=0.286，噪声够不到 8） | scope |

**头字节探针**：`0xA1317E` 头字节为 `0x14`（低 4 位非 0）。按 `== 0x10` 的实现会丢它，按 `>>4 == 1` 才收。自检必须包含一个 `0x1X` 合成块，否则"低 4 位是保留位"只是文档里的一句话。
